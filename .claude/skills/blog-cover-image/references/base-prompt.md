# 封面图生成基础提示词

以下是发送给图像生成模型的系统级指令，每次生成时作为提示词的前置部分。

## 图片规格

- **类型**：博客文章封面图
- **画幅**：16:9

## 核心原则

- 大量留白，突出核心信息，避免杂乱布局
- 主视觉元素居中或偏左（右侧留给标题区域，如果包含标题）
- 人物用简化轮廓表示——不要写实人脸或身体
- 用简洁、可识别的图标来表达概念
- 如果内容涉及敏感或版权相关的元素，创建风格相似的替代品——不要拒绝生成

## 六个维度

### 类型（视觉构图）
- `hero`：大焦点视觉（60-70% 面积），戏剧化构图
- `conceptual`：抽象形状，信息层级，清晰分区
- `typography`：标题为主要元素（40%+ 面积），极少视觉元素
- `metaphor`：用具象事物表达抽象概念，象征性元素
- `scene`：氛围环境，叙事元素，情绪灯光
- `minimal`：单一焦点元素，大量留白（60%+）

### 色板（配色方案）
应用指定色板的颜色值和装饰风格：
- 主色用于主要视觉元素
- 背景色用于底色和周围区域
- 强调色用于高亮和次要元素

### 渲染（视觉风格）
- `flat-vector`：干净轮廓、均匀填充、无纹理、几何图标
- `hand-drawn`：素描感、有机线条、涂鸦风
- `painterly`：柔软边缘、笔触感、水彩/油画风
- `digital`：精确、渐变、抛光感
- `pixel`：8-bit 像素风、网格对齐
- `chalk`：粉笔质感、黑板风

### 文字（密度级别）
- `none`：无文字元素，全视觉面积
- `title-only`：单标题，85% 视觉面积

技术博客封面默认用 `none`（AI 生成的文字通常不准确）。

### 情绪（情感强度）
- `subtle`：低对比度，柔和/减饱和色彩，轻视觉重量
- `balanced`：中等对比度，正常饱和度，均衡视觉重量
- `bold`：高对比度，鲜艳/高饱和色彩，重视觉重量

## 构图指导

- **充足留白**：保持 40-60% 呼吸空间
- **视觉锚点**：主元素居中或偏左
- **信息层级**：一个主焦点，1-2 个辅助元素，装饰性点缀
- **干净背景**：纯色或微妙渐变，避免复杂纹理

## 图标词汇表

| 主题 | 图标元素 |
|------|---------|
| 技术/开发 | 代码窗口、齿轮、电路板、云、锁、API 括号 |
| 创意/创新 | 灯泡、火箭、靶心、拼图、钥匙、放大镜 |
| 网络/连接 | 节点网络、隧道、数据流、信号波 |
| 工具/方法 | 扳手、清单、铅笔、时钟 |
| 增长/商业 | 图表、箭头、植物/芽、山峰 |
| AI/机器学习 | 大脑、神经网络、机器人、芯片 |

## 禁止事项

- 不要包含文字、水印或 logo（结尾加 "No text, no watermarks, no logos."）
- 不要写实人脸
- 不要过于复杂的场景
