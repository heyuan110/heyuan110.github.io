# 标题/描述模板化 A/B Playbook

## 目标

- 提升 SERP CTR（不影响既有内容结构）
- 保持可维护：通过模板注释和人工检查清单执行

## 标题模板（A/B）

### A（问题解决型）

`{核心关键词} + {结果承诺/收益} +（{年份/版本}）`

示例：
- `Docker Compose 完全指南：从 0 到可上线（2026）`

### B（对比决策型）

`{关键词1} vs {关键词2}：{适用场景/结论}`

示例：
- `Claude Code vs Cursor vs Windsurf：2026 实战选型指南`

## 描述模板（A/B）

### A（步骤导向）

`用 1 句话说明对象 + 2~3 个关键覆盖点 + 明确受众 + 预期结果`

### B（痛点导向）

`常见痛点 + 解决路径 + 成果指标（时间/效率/稳定性）`

## 约束规则

- 标题建议 45~65 中文字符（避免截断）
- 描述建议 120~160 中文字符
- 关键词前置（前 18 个字符尽量出现主词）
- 禁止堆砌关键词；每页只保留一个核心搜索意图

## 模板层落地说明

- 在 `layouts/partials/extra-head.html` 中已添加注释：
  - `<!-- 标题/描述模板化 A/B 规则说明见 docs/seo/title-description-playbook.md -->`
- 现有内容不被覆盖：仍优先使用 front matter 的 `title/description`

## 发布前检查清单

- [ ] 标题是否包含主关键词且可读
- [ ] 描述是否与正文前 30% 内容一致
- [ ] 搜索意图是否单一（教程/对比/定义）
- [ ] 是否避免“最强/终极/100%”等过度承诺
