On macOS, files and folders that start with a dot (`.`) are hidden by default. Here's how to toggle their visibility. <!--more-->

## Using Terminal Commands

You can toggle hidden file visibility with simple shell scripts:

**Hide hidden files:** `sh hideallfiles.sh`

**Show hidden files:** `sh showallfiles.sh`
